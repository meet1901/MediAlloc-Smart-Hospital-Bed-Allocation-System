# 🏥 MediAlloc – Smart Hospital Bed Allocation System

## Overview

MediAlloc is a smart hospital bed allocation system designed to improve patient admission efficiency and optimize bed utilization across multiple hospital departments.

The system automatically allocates beds based on patient priority while ensuring effective resource utilization and reducing admission delays.

---

## Features

✅ Priority-based bed allocation

✅ Automatic patient shifting across departments

✅ Waiting list management

✅ Patient discharge and reallocation

✅ Real-time bed availability tracking

✅ Interactive ward-wise bed visualization

✅ Multi-department coordination

## System Workflow

1. Patient admission request
2. Priority evaluation
3. Bed availability check
4. Automatic allocation
5. Patient shifting (if required)
6. Waiting list management
7. Discharge and reallocation

---

## Key Innovation

Unlike traditional systems that directly place patients on a waiting list when departments are full, MediAlloc introduces:

* Priority Replacement
* Automatic Patient Shifting
* Cross-Department Coordination

This improves bed utilization and enables faster admission of critical patients.
